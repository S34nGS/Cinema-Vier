### Hoe run ik het project?
Voer het python script ```run.py``` uit en je zal hiermee het project starten, op de 1ste run wordt ook de database hier via aangemaakt.

Je kan dit uitvoeren door in je terminal het volgende te typen
```sh
# alle operating systems
python run.py

# of alleen op Mac/Linux
./run.py 

# of alleen op windows
.\run.py
```

### Hoe maak ik de database opnieuw aan?
Dit kan op 2 manieren, via het ```CreateDB.py``` script, of door handmatig de database te verwijderen en het run script opnieuw uit te voeren.

Je kan het script uitvoeren door in je terminal het volgende te typen.
```sh
# alle operating systems
python CreateDB.py

# of alleen op Mac/Linux
./CreateDB.py

# of alleen op windows
.\CreateDB.py
```

<summary><strong>English</strong></summary>

### How do i run the project?
Execute the python script ```run.py``` and you will start the project with this, the database will also be created on the first run.

You can execute this by typing the following into your terminal
```sh
# All operating systems
python run.py

# Mac/Linux only
./run.py

# Windows only
.\run.py
```

### How do i create the database again?
This can be done in 2 ways, by using the ```CreateDB.py``` script or by manually deleting the database and running the run script again.

You can execute this by typing the following into your terminal
```sh
# All operating systems
python CreateDB.py

# Mac/Linux only
./CreateDB.py

# Windows only
.\CreateDB.py
```
